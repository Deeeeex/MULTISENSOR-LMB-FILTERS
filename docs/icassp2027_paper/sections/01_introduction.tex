\section{Introduction}
\label{sec:introduction}

Distributed multi-object tracking lets a sensor network combine complementary fields of view without routing all measurements to a central processor. Labeled random finite-set filters, and in particular the labeled multi-Bernoulli (LMB) family, are attractive in this setting because they maintain object existence, kinematic uncertainty, and track identity in a single posterior representation \cite{Vo2014LRFS,Reuter2014LMB,Vo2019MSGLMB}. The practical difficulty is communication. A multi-sensor LMB posterior can contain many labels and multiple Gaussian components per label, so repeatedly broadcasting full Gaussian-mixture posteriors is expensive for bandwidth-limited platforms.

A common response is to communicate less often or with fewer neighbors. This is appealing, but it can attack the wrong bottleneck. Conservative fusion rules such as covariance intersection, generalized covariance intersection, and Kullback-Leibler average (KLA) fusion are designed to combine partially dependent estimates without requiring unknown cross-correlations \cite{JulierUhlmann1997CI,Battistelli2014KLA}. In a distributed tracker, however, the quality of the fused posterior depends not only on whether the nominal graph is connected, but also on which posterior messages actually enter the fusion step at each time. If event triggers or topology adaptation remove too many effective message paths, consensus and label agreement can degrade even while byte counts improve.

This paper takes a different position: preserve the effective fusion graph first, then reduce the payload carried by each message. The key observation is implementation-driven. In many practical GA/KLA-LMB fusion pipelines, incoming LMB components are aligned by label and reduced to label-wise Bernoulli moments before fusion. If the downstream fusion rule consumes these moments, transmitting every Gaussian-mixture component may be unnecessary in regimes where a single Gaussian moment is an adequate summary. This suggests a light posterior message containing the existence probability, mean, covariance, and minimal label metadata for each active Bernoulli component.

We study this idea in a distributed 4+4 multisensor formation benchmark. The baseline periodically exchanges full LMB posteriors over the static communication graph. The proposed light-posterior exchange keeps the same graph and synchronization schedule, but replaces each full Gaussian-mixture label density with its moment-matched single-Gaussian approximation. This design deliberately avoids graph sparsification: every baseline information path remains available to the KLA update, while communication is reduced by changing the representation of each label.

The empirical result is simple but instructive. Over 50 held-out trials, periodic light-posterior exchange reduces estimated communication by 58.6\% relative to periodic full-posterior exchange, while matching the baseline local E-OSPA, consensus OSPA, position-disagreement, cardinality-dispersion, and effective-weight graph connectivity metrics. In contrast, dynamic-topology variants that alter the communication graph are less stable in the same benchmark. These results support a narrow claim: for single-round distributed GA/KLA-LMB fusion with label-wise moment matching, full posterior exchange can be overkill, and graph-preserving payload compression is a safer first lever than sparse event-triggered communication.

The contributions are:
\begin{itemize}
    \item a graph-preserving light posterior exchange protocol for distributed LMB fusion, using label-wise moment-matched Bernoulli messages instead of full Gaussian-mixture posterior messages;
    \item an effective-fusion-graph perspective that separates payload compression from message-path sparsification; and
    \item a held-out 50-trial validation showing full-posterior-equivalent tracking and consensus with about 58\% lower estimated communication in a 4+4 multisensor benchmark.
\end{itemize}
