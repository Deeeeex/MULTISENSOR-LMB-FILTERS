\section{Introduction}
\label{sec:introduction}

Distributed multi-object tracking lets a sensor network combine complementary
views without centralizing all measurements. Labeled random finite-set filters,
especially labeled multi-Bernoulli (LMB) filters, are well suited to this task
because they represent target existence, state uncertainty, and identity in one
posterior \cite{Vo2014LRFS,Reuter2014LMB,Vo2019MSGLMB}. Their communication
cost can be high: each transmitted LMB posterior may contain many labels and
multiple Gaussian components per label.

Most communication-saving designs reduce how often nodes communicate or which
neighbors they contact. That can be risky for conservative fusion rules such as
covariance intersection and Kullback-Leibler average (KLA) fusion
\cite{JulierUhlmann1997CI,Battistelli2014KLA}. The relevant object is not only
the nominal graph, but the effective graph of posterior messages that actually
enter the fusion step. Sparsifying this graph can reduce bytes while degrading
consensus and label agreement.

This paper instead keeps the effective graph intact and compresses the payload.
The observation is simple: in our single-round GA/KLA-LMB fusion path, incoming
components are aligned by label and reduced to Bernoulli moments before fusion.
When the receiver consumes those moments, transmitting every mixture component
can be unnecessary. We therefore send a light posterior containing each active
label's existence probability, moment-matched mean, and moment-matched
covariance over the same static communication graph used by the full-posterior
baseline.

Over 50 held-out trials on an eight-sensor 4+4 formation benchmark, this
periodic light-posterior exchange reduces estimated communication by 58.6\%
while matching full-posterior exchange in local E-OSPA, consensus OSPA,
position disagreement, cardinality dispersion, and effective-weight graph
connectivity. Dynamic-topology variants are less stable, supporting the paper's
central design rule: preserve information paths first, then compress posterior
payloads.

Our contributions are a graph-preserving light posterior exchange protocol for
distributed LMB fusion, an effective-fusion-graph perspective that separates
payload compression from message-path sparsification, and a held-out 50-trial
validation showing full-posterior-equivalent behavior with about 58\% lower
estimated communication.
