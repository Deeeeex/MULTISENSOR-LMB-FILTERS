\section{Conclusion}
\label{sec:conclusion}

We derived a receiver-induced moment message from an executed projected
KLA-LMB receiver. Sender-side projection preserved every audited fusion output
and reduced attempted application-layer bytes by 58.28\% across 50 paired
trials. The certificate includes label presence, Metropolis weights, numerical
regularization, and canonical transport. It is exact for this receiver, not a
general equivalence result for mixture-aware or multi-round KLA fusion.
