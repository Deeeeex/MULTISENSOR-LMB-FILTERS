\section{Conclusion}
\label{sec:conclusion}

We derived a fusion-sufficient moment message from a projected Gaussian KLA-LMB
receiver. Moving the receiver's idempotent moment projection to the sender
preserved every audited fusion output. It reduced attempted application-layer
bytes by 58.28\% across 50 paired trials. This exact result is receiver-specific,
not a general mixture-aware KLA equivalence result. Future tests should cover quantized
links, multi-round reuse, and receivers that retain multimodality.
