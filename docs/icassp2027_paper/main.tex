\begin{abstract}
In the studied distributed tracker, the network interface transmits full Gaussian-mixture (GM) messages even though the receiver discards mixture structure before fusion. We treat this mismatch as a message-interface problem for a projected Kullback--Leibler-average labeled multi-Bernoulli (KLA-LMB) receiver. Factoring its implementation into a canonical label-wise moment projection and downstream fusion identifies a receiver-induced equivalence class. Under matched active labels, Metropolis weights, delivery masks, and numerical conventions, sender-side projection preserves every fused existence probability, mean, and covariance. We realize the interface with a versioned binary application-layer codec. In 50 paired eight-sensor trials, moment exchange reduced attempted payload bytes by 58.28\% (95\% bootstrap interval: 57.92--58.64\%). All 1,119,037 audited label-instance outputs were identical. The certificate removes representation-level traffic without changing this receiver's output; it does not extend to mixture-aware or multi-round consumers.
\end{abstract}
