# 定向任务路由：M24/X36 关键发现

## 结论

原来的方法把“是否连接两个节点”和“两个方向如何融合”绑定在一起：
一条无向边一旦被选中，两个端点都会用 Metropolis 权重进行对称 KLA。
实验表明，问题的主要矛盾并不是候选图太少或拓扑切换不够频繁，而是
**并非每个邻居后验都值得被每个接收节点融合**。较弱后验反向进入较好
节点时，会稀释后者的估计；因此增加普通共识轮数反而可能继续恶化结果。

新的设计把一个拓扑动作拆成三个接收端决策：

1. 哪个接收节点当前需要外部信息；
2. 哪个物理邻居适合作为发送端；
3. 该发送端在本轮 KLA 中应占多大权重。

发送端不因这次传输而被反向修改，接收端也可以拒绝所有邻居。这个设计
把“维持全网每轮连通”改成“只路由当前有任务价值的信息”。连接安全仍由
物理可达性、定向消息预算和非负归一化融合权重约束保证。

## 为什么改变方法

在 M24 的同一后验检查点上，将普通全图 KLA 重复两到三轮没有带来更好
的一致性：

| 方案 | 任务风险 | 相对单轮静态图 |
|:--|--:|--:|
| 静态图，1 轮 | 0.16695 | 基准 |
| 静态图，2 轮 | 0.19094 | 变差 14.37% |
| 静态图，3 轮 | 0.21371 | 变差 28.01% |
| 旧拓扑教师，1 轮 | 0.16303 | 改善 2.35% |
| 旧拓扑教师，2 轮 | 0.18032 | 变差 8.01% |
| 旧拓扑教师，3 轮 | 0.19267 | 变差 15.40% |

放宽拓扑 churn 限制也没有改变旧教师的选择或其约 2% 的代理收益。这两项
反证共同说明，继续在“无向图选择 + 对称融合”框架内扩大搜索或增加共识轮
数，不是当前最有希望的方向。

## 方法原型

特权教师逐接收节点枚举物理邻居和候选 KLA 权重
`[0.15, 0.30, 0.50, 0.70]`，只在该节点的标签化任务风险下降时接受一条
定向消息。教师会读取真值，只用于检验方法空间和生成训练标签，不能部署。

部署策略不读取真值。它使用 21 个当前可观测特征，包括链路可靠性、节点
距离、编队关系、存在概率与基数不确定性、位置协方差、关联置信度、检测
质量、共享标签状态差异，以及发送端相对接收端的质量优势。第一版模型采用
可检查的 k 近邻评分器，为每个接收端至多选择一个发送端，并同时预测融合
权重。轻量模型的目的不是把 kNN 本身作为最终贡献，而是先验证“数据驱动的
接收端路由”能否跨网络规模迁移；后续可以在同一接口上替换为 GNN。

## 教师空间是否存在

在共同的 seed 7、`t=75` 后验检查点上，定向教师给出了很大的可实现空间：

| 场景 | Static E-OSPA | Local E-OSPA | 定向教师 E-OSPA | 相对 static | 相对 local | Static bytes | 教师 bytes |
|:--|--:|--:|--:|--:|--:|--:|--:|
| M24-hard | 25.5087 | 24.5451 | 15.4348 | 改善 39.49% | 改善 37.12% | 2,808,536 | 1,158,960 |
| X36-clean-scale | 46.8048 | 44.4497 | 29.7757 | 改善 36.38% | 改善 33.01% | 6,648,128 | 2,563,592 |

这说明旧方法在 X36 上失败，并不等于动态通信没有价值；更准确的解释是，
旧动作空间强制对称融合，无法表达“只让需要帮助的节点接收一个更可靠后验”。

## 部署策略训练

M24 seed 7、`t=75` 产生 552 个物理定向边样本，覆盖 24 个接收节点。
训练标签来自特权教师，输入特征均不使用真值。按接收节点分组的四折交叉
验证选择了 `k=40`、预测收益阈值 `0` 和正收益邻居置信度阈值 `0.70`：

| 接收端留出指标 | 数值 |
|:--|--:|
| 平均已选动作收益 | 15.21% |
| 最小已选动作收益 | 0.00% |
| 选到负收益动作的比例 | 0.00% |
| 选择通信的接收节点比例 | 70.83% |
| 捕获的教师正收益 | 42.63% |

这个留出方式避免同一接收节点的入边同时出现在训练和验证折中，但仍不是
seed 或时间留出。M24 的 `t=75` 结果因此属于训练检查点，不能当作泛化证据。

同一模型未使用任何 X36 标签或真值，直接从 M24 迁移到 X36：

|:--|:--|--:|--:|--:|--:|--:|--:|
| M24-hard | Local | 24.5451 | 42.9270 | 26.4274 | 0.8333 | 0 | 0 |
| M24-hard | Static | 25.5087 | 42.6616 | 27.9094 | 0.9167 | 2,808,536 | 58 |

| X36-clean-scale | Static | 46.8048 | 68.6548 | 36.8924 | 2.4444 | 6,648,128 | 88 |
| X36-clean-scale | Learned directed | **41.6002** | **61.7640** | **33.1179** | **1.9722** | **1,385,064** | 18 |

M24 相对 static 和 local 的平均 E-OSPA 分别改善 39.49% 和 37.12%，通信量
为 static 的 41.27%。最差节点相对 static 数值上轻微变差 0.22%，相对
local 改善 0.40%，因此保留严格的尾部风险 caveat。

X36 是当前更有信息量的结果：同一个 M24 模型零样本迁移后，相对 static
改善 11.12%，相对 local 改善 6.41%，最差节点不劣于 local、相对 static
改善 10.04%，通信量仅为 static 的 20.83%。这已经说明 M24/X36 并非
“都没有好效果”，但证据强度仍只到单 seed、单检查点的软件与方向筛查。

## 三步闭环检查

将共同检查点后的条件续跑扩展到 `t=75–77` 后，路由动作会改变下一步后验，
因此可以检查第一步优势是否被闭环反馈抵消：

| 场景 | Learned E-OSPA | Static | Local | 相对 static | 相对 local | Worst vs static | Worst vs local | Bytes/static |
|:--|--:|--:|--:|--:|--:|--:|--:|--:|
| M24-hard | **15.3711** | 25.3731 | 23.4600 | **改善 39.42%** | **改善 34.48%** | **改善 18.61%** | **改善 17.50%** | 30.93% |
| X36-clean-scale | **38.5310** | 46.3716 | 43.1425 | **改善 16.91%** | **改善 10.69%** | **改善 7.64%** | 0.00% | 20.27% |

三步结果没有出现收益衰减。M24 的单步最差节点 caveat 在三步平均中消失，
X36 相对 static 和 local 的平均优势也从 11.12%/6.41% 增加到
16.91%/10.69%。两个场景均保持零拓扑不可行，并显著少于 static 的
attempted payload bytes。这使“定向接收端路由”从瞬时动作信号提升为初步
闭环方法信号，但仍未跨越随机 seed。

## 证据边界与下一步

- 当前比较只覆盖 seed 7、`t=75–77` 的三步条件续跑，不代表完整轨迹。
- M24 检查点参与了训练；X36 是跨规模零样本检查，但仍共享同一个随机 seed。
- kNN 的接收端留出结果不是 seed、时间或场景留出结果。
- static 是全时段几何与链路距离选出的固定图，不是穷举得到的最强跟踪固定图。
- 当前 KLA 参考保留多分量，但仍是 componentwise powered-GM 近似，不是
  任意 Gaussian mixture 密度幂的精确实现。
- attempted bytes 只统计 posterior payload；控制、ACK 和策略协商开销尚未计入。

下一阶段应增加 M24/X36 的 seed 与时间留出，并训练/验证更强的固定图
基线。只有这些结果仍保持平均收益、尾部安全和通信优势，才适合把 GNN
替换 kNN 并形成论文级方法与理论分析。
