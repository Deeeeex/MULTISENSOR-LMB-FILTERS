# 保留强主干的动态残差路由：设计与实验门槛

## 1. 为什么再次改变动作空间

上一版 return-first 方案允许动态策略用一条新输入替换每个接收节点的安全循环输入。M24 的特权策略虽然满足滚动 \(B=3\) 信息流、安全修复和通信量约束，却仍显著弱于固定索引路由。这说明瓶颈不只在“能否学会给图打分”，而在更前面的动作定义：动态跨编队边在带来新信息的同时，也删除了原本对跟踪最有用的编队内输入。

因此，新方案不再要求一条边同时承担“稳定跟踪”和“跨编队探索”两个相互冲突的职责，而把它们拆开：

- 高权重主干输入负责保留稳定的局部估计质量；
- 低权重残差输入负责维持时间展开的信息流，并按当前状态交换跨编队信息；
- 动态策略只能改变残差输入，不能删除主干输入。

## 2. 融合规则

对接收节点 \(i\)，记本地后验为 \(p_i\)，固定索引主干发送者为 \(b_i\)，动态残差发送者为 \(r_i(t)\)。在线融合采用

\[
p_i^+(x)\propto
p_i(x)^{1-\alpha-\epsilon}
p_{b_i}(x)^\alpha
p_{r_i(t)}(x)^\epsilon ,
\]

其中本轮冻结

\[
\alpha=0.70,\qquad
\epsilon=0.05,\qquad
1-\alpha-\epsilon=0.25 .
\]

如果 \(b_i=r_i(t)\)，两项自动合并成一次消息和权重 \(0.75\)，不会重复发送同一个后验。每个接收节点最多消费两条邻居消息，整个网络每轮最多尝试 \(2S\) 条有向消息。

为避免动态策略仅靠“把原本合并的一条消息拆成两条”获得额外通信量，安全循环中与主干发送者重合的接收节点不允许成为跨编队残差边的端点。动态动作只替换主干与残差原本不同的那部分路由，因此每轮实际消息条数与同结构静态残差对照完全一致；候选发送者的 payload 大小差异再由 2% 字节约束控制。

这不是在原固定索引方案上事后添加一个任意调参项。权重分工是设计的一部分：\(\alpha\) 保持原先较强的固定索引融合强度，较小的 \(\epsilon\) 把拓扑变化限制为对强基线的受控扰动。

## 3. 安全投影

固定主干始终存在。残差路由以固定平衡循环为无操作基线，并沿用精确的滚动 \(B=3\) 投影器：

1. 根据当前后验、链路可靠性或外部边价值分数提出残差跨编队边；
2. 联合检查当前动作与下一步保留动作；
3. 只接受能使实际组合图在所有成熟三步窗口内保持传感器级和编队级强连通的动作；
4. 投影不可行、触发修复或通信紧急回退均记为失败，而不是静默替换结果。

安全性约束针对在线实际使用的“主干与残差的并图”。因此，即使主干本身补足了某条安全路径，报告的 \(B=3\) 结论仍对应实际信息流，而不是一个未执行的名义残差图。

## 4. 数据驱动部分的理论接口

部署时的学习器不直接输出任意邻接矩阵，而只对物理可用的候选残差边估计边际长期价值。记当前可观测状态为 \(s_t\)，残差动作为 \(a_t\)，跟踪损失为 \(\ell_t\)，则训练目标为

\[
Q_H(s_t,a_t)=
\mathbb{E}\!\left[
\sum_{h=0}^{H-1}\gamma^h
\bigl(
\ell_{t+h}^{\mathrm{static\ residual}}
-\ell_{t+h}^{a_t}
\bigr)
\mid s_t,a_t
\right].
\]

策略输出的分数只决定残差候选的优先级，最终图仍由确定性的安全投影器生成。这样把难题分成两个可审计部分：

- 学习器解决“哪条附加信息在当前状态下更有价值”；
- 投影器解决“哪些边的组合满足滚动连通和消息预算”。

由于动态项的总融合权重只有 \(\epsilon\)，后续理论分析可以从主干融合算子附近的扰动出发，研究残差边选择误差如何传递到存在概率、状态密度和网络分歧。这里不能预先声称误差界成立；当前实现只是为这一分析建立了明确且可控的算法接口。

## 5. M24 开发门槛

本轮先用 seed 7、\(t=75{:}77\) 检查动作空间是否存在足够上界。冻结的比较臂为：

| 类别 | 实验臂 |
|---|---|
| 无通信下界 | local |
| 强单输入基线 | fixed-index, \(w=0.50\) |
| 强单输入基线 | fixed-index, \(w=0.70\) |
| 同消息结构静态对照 | fixed-index 主干 + fixed-cycle 残差，\(\alpha=0.70,\epsilon=0.05\) |
| 可部署解析对照 | 主干 + posterior-analytic 残差 |
| 非部署上界 | 主干 + truth-assisted current-risk 残差 |
| 非部署上界 | 主干 + truth-assisted minimax 残差 |

特权上界必须同时满足：

- 平均 E-OSPA 相对三个通信基线中的每一个至少改善 5%；
- 最差节点 E-OSPA 不劣于三个通信基线和 local；
- 尝试字节数相对同结构静态残差对照偏差不超过 2%；
- 所有成熟的传感器级和编队级 \(B=3\) 窗口均强连通；
- 一步安全储备检查全部通过；
- 拓扑不可行、投影修复和通信紧急回退次数均为零。

特权策略读取真实目标状态，只用于回答“这个动作空间是否有上界”，不能作为可部署算法或论文结果。M24 未通过上述门槛时，不生成长期回报标签、不训练图模型，也不运行 X36 学习策略。

## 6. 后续顺序

只有 M24 动作空间通过后，才依次进行：

1. 生成多步配对回报数据；
2. 训练图结构的残差边价值模型；
3. 在未参与训练的 M24 seeds 上冻结模型并验证；
4. M24 通过后才做 X36 规模迁移；
5. 最终用不少于 30 个配对 seeds 给出置信区间、通信量、安全违例和跟踪收益。

现阶段的研究结论必须严格停留在相应证据层级：动作空间上界、开发集模型结果、留出验证和论文级结论不能相互替代。

## 8. v2-e10 结果与上界定义修正

v2-e10 的静态残差为 18.8127，特权 current/minimax 为 18.4231，相对同结构静态臂仅改善 2.07%；解析动态残差退化到 19.7353。字节偏差 0.20%、最差节点、安全窗口、零修复和零紧急回退仍通过，但总体门槛失败。因此不能把 v1 的边界结果解释成“只要提高残差权重就会过线”，也不继续做权重扫描。

更重要的修正是：current/minimax 教师根据当前融合后验的真值风险选择边，最终审计却使用三步闭环 E-OSPA。该教师是有特权的即时启发式策略，却不是三步回报意义上的动作空间上界。未来测量和传感器接力可能改变边的长期价值，因此“即时教师未过线”不能严格推出“动作空间没有可学习的长期收益”。

下一阶段先构造 return-aware headroom：

1. 在冻结的 \(t=75\) 决策状态上，用不含真值的多种可观测打分方向和离线真值打分生成一组不同的安全残差图；
2. 每个候选图必须原样执行为第一步，后续使用同一个冻结的真值无关安全控制；
3. 所有候选复用相同测量、链路随机数、初始后验和历史图；
4. 用真实三步闭环 E-OSPA 排序候选，只把“最佳候选与强控制之间的差”用作非部署上界；
5. 只有该上界通过原 5%/尾部/字节/\(B=3\) 门槛，才授权生成更大规模回报数据和训练图价值模型。

这一步会把“动作空间是否有长期价值”和“即时教师是否会选边”分离开，避免用错误的教师能力替代方法上界。

CSC 是约束合格序列中的最好结果。它的三个传感器级和编队级滚动窗口
全部强连通，repair、payload emergency 和 topology infeasibility 均为零，
真值读取比例与两个 C 步精确一致。相对最强平均 E-OSPA 基线
18.7966 的改善为 4.0175%，仍低于预注册的 5%。因此失败原因不是安全、
通信量或来源审计，而是这个动作空间的估计收益上界不足。

这同时否定了“只要学习何时在 S/C 之间切换即可达标”的假设。当前不授权
生成该二元策略的长期回报数据，不训练其图模型，也不运行 X36。

下一次结构改变不再扫描 \(\epsilon\) 或 S/C 时机，而扩大低权重残差路由
本身的表达能力：保持固定索引主干和 \(\alpha=0.70,\epsilon=0.05\)
不变，把每步最多 \(G-1\) 条跨编队残差边改为一个含 \(G\) 条边的有向
编队循环。每个编队提供一个跨编队入口，端点由边价值选择；其余残差输入
保持静态。总残差输入数量不增加，只把原有低权重输入重新路由，因此仍须
与同消息数的固定端点循环对照，并独立检查实际字节和传感器级 \(B=3\)。
这个动作空间把可学习部分限定为“选择循环方向和网关端点”，同时让编队级
信息流在每一步而非三步并图后才强连通，适合后续用图模型扩展到更多编队。

实现采用“切环再拼接”的精确投影。每个编队原有的低权重残差输入构成一个
传感器有向环；策略在每个局部环上选一个切口，把被切边的发送端接到下一个
编队的切口接收端。经过 \(G\) 次重接后，\(G\) 个局部环变成覆盖全网所有
传感器的一个有向环。因此残差图本身在每一步就具有强连通性，而且每个
传感器仍恰好有一个残差输入和一个残差输出。投影只允许不会把残差输入与
主干输入合并或拆开的切口，所以并图后的消息数与静态残差对照严格相等。
给定候选边分数后，两个循环方向上的最优切口由确定性的动态规划求出；
安全结构不依赖学习器能否正确打分。
