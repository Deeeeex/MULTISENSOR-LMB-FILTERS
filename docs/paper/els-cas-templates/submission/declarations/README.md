# Submission Declarations

Information Fusion / Elsevier currently splits these declaration items across the manuscript and submission attachments:

- Keep in manuscript before the reference list: CRediT authorship contribution statement, funding, data availability, and generative AI disclosure if AI tools were used.
- Upload separately: declaration of competing interest. Elsevier asks authors to complete the declarations tool and upload the resulting Word document at the attach/upload files step.

The files in this directory are editable drafts for final manual confirmation. The competing-interest text here is not a substitute for the official Elsevier declarations-tool Word document.
