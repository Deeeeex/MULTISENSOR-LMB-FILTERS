\section{Problem Formulation}
\label{sec:problem-formulation}

Consider a distributed network with sensor set $\mathcal{V}=\{1,\ldots,S\}$ and discrete times $k \in \{1,\ldots,T\}$. The multi-object state at time $k$ is the labeled random finite set $X_k$. Each sensor $s \in \mathcal{V}$ acquires a local measurement set $Z_k^{(s)}$. Under the standard RFS/FISST formulation, each node maintains an LMB approximation to its local posterior \cite{Mahler2003PHD,Mahler2007FISSTBook,Vo2014LRFS,Reuter2014LMB,Vo2019MSGLMB}. Its Bernoulli components jointly encode target existence, kinematic state, and identity. The fusion layer must combine neighboring posteriors without assuming that their cross-correlations are known.

\subsection{Local LMB posterior model}

Let $\mathcal{N}_s \subseteq \mathcal{V}$ denote the communication neighborhood of sensor $s$, including the node itself. Sensor geometry and communication range induce the graph used to construct $\mathcal{N}_s$. Each node solves a local fusion problem over only these indices. The next subsection defines the delivered measurement stream and statistics for every neighbor. Prediction, measurement update, and association on stream $j \in \mathcal{N}_s$ produce one LMB posterior for fusion. We denote its finite parameter set by $\Theta_k^{(j)}$,
\begin{equation}
\Theta_{k}^{(j)} = \left\{ \left(r_{k,i}^{(j)}, p_{k,i}^{(j)}(\cdot,\ell_i)\right) \right\}_{i=1}^{M_k},
\end{equation}
where $\mathcal{L}_k=\{\ell_1,\ldots,\ell_{M_k}\}$ is the aligned label set and $M_k$ is its size. The quantity $r_{k,i}^{(j)} \in [0,1]$ is the Bernoulli existence probability. The function $p_{k,i}^{(j)}$ is the spatial density for label $\ell_i$. The corresponding LMB density is the standard labeled-RFS density induced by this parameter set,
\begin{equation}
\pi_k^{(j)}(X)
=
\Delta(X)\,
w_k^{(j)}\!\left(\mathcal{L}(X)\right)
\prod_{(x,\ell_i)\in X}p_{k,i}^{(j)}(x,\ell_i),
\end{equation}
with
\begin{equation}
w_k^{(j)}(L)
=
\prod_{\ell_i\in L}r_{k,i}^{(j)}
\prod_{\ell_i\in \mathcal{L}_k\setminus L}\left(1-r_{k,i}^{(j)}\right),
\qquad
L\subseteq\mathcal{L}_k.
\end{equation}
Here $\Delta(X)$ is the distinct-label indicator and $\mathcal{L}(X)$ is the set of labels present in $X$. The compact parameter-set notation $\Theta_k^{(j)}$ is used below whenever the implementation operates on the Bernoulli components rather than on the full finite-set density. Thus the fusion layer below consumes LMB posterior parameters; raw measurement sets enter only through the local measurement update and the realized delivery statistics.

\subsection{Communication-constrained delivery}

The communication model used in the experiments acts on measurement streams before distributed LMB fusion. At time $k$, the raw measurement set $Z_k^{(j)}$ generated by sensor $j$ is converted into a delivered set $\tilde{Z}_k^{(j)}$ by a communication layer with three possible effects:
\begin{enumerate}
\item a global or per-step bandwidth budget that limits how many measurements can be delivered,
\item a stochastic packet-drop model on each sensor stream,
\item optional node-level outages.
\end{enumerate}
For node $s$, the local fusion problem is assembled from the delivered streams $\{\tilde{Z}_k^{(j)}:j\in\mathcal{N}_s\}$ and the matching delivery statistics. Prediction and measurement update on these streams produce the posteriors $\{\pi_k^{(j)}:j\in\mathcal{N}_s\}$ that are fused in the GA-LMB step. The delivery statistics also define the availability and link-quality factors used by the adaptive weights. Let $m_k^{(j)} \in \{0,1\}$ denote the availability indicator of neighbor index $j$ at time $k$, and let $\rho_k^{(j)} \in [0,1]$ denote the realized delivery-quality statistic derived from delivered-versus-dropped measurements.

\subsection{Distributed KLA fusion objective}

Because cross-correlations among neighboring LMB posteriors are unknown, exact Bayesian fusion is generally unavailable. We therefore use the geometric-average realization of Kullback--Leibler averaging as the main conservative fusion rule. This rule is also known as generalized covariance intersection. At node $s$, the target density fused over $\mathcal{N}_s$ is
\begin{equation}
\label{eq:ga-kla-objective}
\bar{\pi}_k^{(s)}(X) \propto \prod_{j \in \mathcal{N}_s} \left(\pi_k^{(j)}(X)\right)^{\omega_{k,s}^{(j)}},
\qquad
\sum_{j \in \mathcal{N}_s} \omega_{k,s}^{(j)} = 1,
\qquad
\omega_{k,s}^{(j)} \ge 0,
\end{equation}
where $\omega_{k,s}^{(j)}$ is the weight assigned by node $s$ to neighbor $j$ \cite{Battistelli2014KLA,Hlinka2014ICI}. Some fusion literature uses KL-averaging terminology more broadly. Here, KLA/GA denotes the geometric-average logarithmic pool in \eqref{eq:ga-kla-objective}. Appendix-only arithmetic-average (AA) diagnostics follow the reverse-KL, minimum-information-loss route \cite{LiCorchadoSun2017GCIAlternative,Gao2020MIL,Li2024AADensityFusion}. Fixed fusion commonly uses uniform or Metropolis consensus weights \cite{XiaoBoydLall2005ConsensusWeights}. Our problem is to adapt these weights to posterior quality and realized communication quality.

In the GA-LMB fusion rule considered here, the spatial and existence parts of each Bernoulli component are fused separately after moment matching. This separation makes it natural to ask whether the same scalar weight should govern both spatial fusion and existence fusion.

\subsection{Adaptive weight-allocation target}

The adaptive layer returns weight vectors on the active-neighbor simplex. Fixed fusion uses one vector $\omega_{k,s}^{(j)}$ for the entire posterior. The proposed rule instead returns a spatial vector $\omega_{k,s}^{x,(j)}$ and an existence vector $\omega_{k,s}^{r,(j)}$. Both vectors are normalized over available neighbors. They may respond differently because Gaussian spatial fusion and Bernoulli existence fusion use distinct algebraic updates. Section~\ref{sec:method} defines the scores and algorithm; this section only specifies the required outputs.

\subsection{Evaluation target}

The aim is to improve both local tracking and agreement among nodes. This distinction is central to the problem. Under unknown cross-correlations and communication losses, distributed fusion should move neighboring nodes toward a shared multisensor picture.

Accordingly, the evaluation uses two complementary metric layers:
\begin{itemize}
\item primary network-level disagreement metrics, which quantify consensus error among the fused outputs of different sensors,
\item secondary truth-referenced local tracking metrics, which verify that consensus-error reductions preserve conventional tracking accuracy.
\end{itemize}

Let $\hat{X}_k^{(s)}$ denote the extracted multi-object estimate at sensor $s$ and time $k$, and let $\hat{n}_k^{(s)} = |\hat{X}_k^{(s)}|$ denote its estimated cardinality. The paper defines the following network-level disagreement metrics:
\begin{align}
D_{\mathrm{OSPA}}(k)
&=
\frac{2}{S(S-1)}
\sum_{1 \le a < b \le S}
d_{\mathrm{OSPA}}\!\left(\hat{X}_k^{(a)}, \hat{X}_k^{(b)}\right),
\\
D_{\mathrm{GOSPA}}(k)
&=
\frac{2}{S(S-1)}
\sum_{1 \le a < b \le S}
d_{\mathrm{GOSPA}}^{(c,p,\alpha)}\!\left(\hat{X}_k^{(a)}, \hat{X}_k^{(b)}\right),
\\
D_{\mathrm{loc}}(k)
&=
\frac{2}{S(S-1)}
\sum_{1 \le a < b \le S}
d_{\mathrm{loc}}\!\left(\hat{X}_k^{(a)}, \hat{X}_k^{(b)}\right),
\\
D_{\mathrm{card}}(k)
&=
\frac{1}{S}
\sum_{s=1}^{S}
\left|
\hat{n}_k^{(s)}
-
\operatorname{median}\!\left(\hat{n}_k^{(1)},\ldots,\hat{n}_k^{(S)}\right)
\right|,
\end{align}
Here, $d_{\mathrm{OSPA}}$ is the optimal subpattern assignment (OSPA) distance between two estimated finite sets \cite{Schuhmacher2008OSPA}. The quantity $d_{\mathrm{GOSPA}}$ is its generalized, unnormalized counterpart \cite{Rahmathullah2017GOSPA,Ristic2011TrackMetric}. The quantity $d_{\mathrm{loc}}$ is localization disagreement after Hungarian matching of common extracted objects \cite{Kuhn1955Hungarian}. We report these quantities as OSPA consensus error, GOSPA consensus error, matched localization disagreement, and cardinality dispersion.

All Euclidean OSPA and GOSPA quantities use cutoff $c=5$ and order $p=2$; GOSPA additionally uses the standard $\alpha=2$. Both metrics use the complete extracted kinematic state vector as their Euclidean ground space, rather than position alone. For sets $X=\{x_1,\ldots,x_n\}$ and $Y=\{y_1,\ldots,y_m\}$ with $n\leq m$, the implementation evaluates
\begin{equation}
d_{\mathrm{GOSPA}}^{(c,p,\alpha)}(X,Y)
=\left[
\min_{\pi}\sum_{i=1}^{n}\min\!\left(c,\lVert x_i-y_{\pi(i)}\rVert_2\right)^p
+\frac{c^p}{\alpha}(m-n)
\right]^{1/p},
\end{equation}
with the arguments exchanged when $n>m$. Unlike OSPA, this expression is not divided by $\max(n,m)$. Additional extracted objects therefore cannot reduce the score through cardinality normalization. Both scores are averaged over unordered sensor pairs, then over time and paired trials. Euclidean OSPA (E-OSPA) compares one node's extracted set with ground truth. It uses the same $(c,p)=(5,2)$ parameters and differs from consensus OSPA only in the reference set.

These network measures use standard ingredients. OSPA and GOSPA are established finite-set metrics, and Hungarian matching provides the assignment primitive \cite{Schuhmacher2008OSPA,Rahmathullah2017GOSPA,Ristic2011TrackMetric}. Pairwise dispersion is a standard measure of disagreement in consensus problems \cite{XiaoBoydLall2005ConsensusWeights}. Our specific choice is the aggregation target. The metrics compare post-fusion outputs across nodes in addition to comparing each node with ground truth. This target matches the central question: whether heterogeneous communication prevents nodes from reaching a common fused picture.

The secondary local metrics remain the standard truth-referenced tracking quantities:
\begin{itemize}
\item local Euclidean OSPA (E-OSPA),
\item local root mean square error (RMSE),
\item local cardinality error.
\end{itemize}
The evaluation is asymmetric by design. Success primarily means lower network disagreement. Local metrics verify that this gain does not cause a clear loss in conventional tracking quality.
