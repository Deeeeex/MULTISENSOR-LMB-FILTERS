\section{Experimental Setup}
\label{sec:experimental-setup}

This section defines the evaluation protocol used to support the paper's claims. The experiments are organized around one main scenario and a small set of supporting studies. The main scenario is the dual-formation eight-sensor distributed GA-LMB tracking problem under tiered heterogeneous packet loss. Supporting studies are used to check whether the observed gains persist under ideal communication, whether the method generalizes beyond the main GA setting, and whether several optional modules should remain outside the core method.

\subsection{Evaluation hierarchy}

The evaluation is intentionally hierarchical. The main experiment is dual-formation eight-sensor distributed GA-LMB tracking under tiered heterogeneous packet loss with factor ablation from fixed weights to the full adaptive method. Supporting experiments include an ideal-communication comparison between ordinary GA, the branch-decoupled backbone, the scalar FID-FIA baseline, and the proposed branch-decoupled fusion, a communication-robustness analysis across communication levels, and an AA-based secondary generalization experiment. Appendix-style ablations include NIS, history, freshness, ambiguity-aware, and cardinality-consensus variants.

\subsection{Main scenario}

The primary evaluation setting uses eight mobile sensors arranged as two four-sensor formations. The filtering mode is distributed local fusion, meaning that each node fuses only its own posterior and the posteriors available inside its communication neighborhood. The local multi-object filter is GA-LMB with loopy belief propagation (LBP) for approximate marginal data association \citep{WilliamsLau2014LBP}.

The common sensor-side configuration is:
\begin{itemize}
\item number of sensors: $8$,
\item filter mode: GA-LMB,
\item data association: LBP,
\item clutter rate: $3$ for every sensor,
\item detection probability: $0.9$ for every sensor,
\item measurement-noise scale: $q = 3$ for every sensor,
\item sensor field of view enabled with half-angle $60^\circ$ and range $60000$.
\end{itemize}

The target side consists of ten objects arranged in three groups with staggered births. The three groups contain $3 + 3 + 4$ targets, respectively, and the targets move toward the central region with nominal speed $0.45$. Births are staggered every eight time steps, and the total simulation length is $100$ steps.

\subsection{Communication model}

The main scenario uses a tiered heterogeneous packet-loss setting. Communication is applied before distributed fusion through a measurement-delivery model with bandwidth limitation and link-level packet loss. The main configuration is:
\begin{itemize}
\item communication level: $2$,
\item global maximum delivered measurements per step: $80$,
\item packet-selection policy: weighted priority with random measurement selection,
\item link model: fixed packet drop,
\item target mean drop rate: $p_{\mathrm{drop}} = 0.2$,
\item tiered drop levels: $[0, 0.1, 0.2, 0.5]$,
\item tiered level counts: $[1, 4, 1, 2]$.
\end{itemize}
This tiered design preserves the historical mean communication degradation while introducing persistent cross-node heterogeneity.

Figure~\ref{fig:scenario-schematic} summarizes the contrast between the simpler standard fixed ideal benchmark and the main tiered-loss scenario. The standard ideal benchmark uses four full-ROI sensors, ideal communication, and fixed target births. The main scenario is the dual-formation eight-sensor case with staggered target waves, a bandwidth cap, and persistent drop-tier heterogeneity before distributed fusion.

\subsection{Mainline ablation protocol}

The core ablation study compares five arms:
\begin{enumerate}
\item fixed fusion weights,
\item adaptive weighting with covariance only,
\item joint covariance-and-link weighting,
\item the three-factor backbone with covariance, link quality, and existence confidence,
\item the branch-decoupled backbone, which adds weak structure-aware modulation after covariance, link-quality, and existence-confidence weighting.
\end{enumerate}

This five-arm path is a design diagnostic for the communication-aware backbone and the pre-refinement branch split. The main confirmation additionally compares the Cao-Zhao scalar FID-FIA baseline and the proposed branch-decoupled fusion; the results table appends this final arm after the five backbone rows to show the branch-specific FID-FIA extension on the same scale. The full adaptive configuration uses exponential smoothing with $\alpha = 0.7$, minimum weight $0.05$, existence-confidence parameters $\lambda_{\min}=0.85$ and $p_e=2.0$, decoupled KLA with spatial and existence strengths $(0.5,0.15)$, and weak structure-aware refinement with spatial and existence strengths $(0.45,0.08)$. Its final branch-specific step applies FID-FIA information geometry only to the existence weights, with existence-branch smoothing and minimum-weight flooring disabled for that refinement. Optional posterior-structure-consistency, NIS, and history modules are disabled in the main configuration.

\subsection{Metrics and reporting}

The experiments report two categories of metrics. The first category is network-level disagreement among sensors after distributed fusion. These primary metrics are consensus OSPA, consensus RMSE, and consensus cardinality disagreement as defined in Section~\ref{sec:problem-formulation}. The second category is conventional truth-referenced tracking accuracy. These secondary metrics are local E-OSPA, local RMSE, and local cardinality error. The OSPA family is used because it provides a mathematically consistent distance for multi-object filtering and tracking evaluation \citep{Schuhmacher2008OSPA,Ristic2011TrackMetric}. Because the consensus metrics are task-specific network-agreement measures, the paper always interprets them together with the secondary local metrics rather than in isolation.

This primary-versus-secondary split is deliberate. The proposed method is not intended as a generic single-sensor accuracy booster. It is designed as a distributed fusion-weight mechanism for improving the consistency of the fused multi-sensor picture under heterogeneous communication. For that reason, the paper treats the network-level disagreement metrics as the main outcome and the local tracking metrics as a safeguard against hidden degradation. In other words, the target is to improve consistency without causing a meaningful drop in conventional tracking quality.

Unless otherwise stated, reported scalar metrics are Monte Carlo means. The main fixed-versus-full adaptive confirmation, the five-arm factor ablation, and the ideal-communication comparison all use 20 deterministic trials with seeds $2$--$21$. The main confirmation and ideal-communication comparison are paired by construction. The five-arm factor ablation remains primarily a design diagnostic, but it is now reported on the same 20-trial seed set for consistency.
