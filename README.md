## 版本怎样区分

同一类方法沿用同一条分支。V278、V291 等编号是实验标识，继续体现在
配置、实验目录、设计记录和提交信息中，不再等同于新分支。
关键节点用附注标签冻结，例如 `icassp2027/baseline-<date>` 或
`icassp2027/method-freeze-<date>`；标签一旦发布不随下一次实验移动。

只有独立的方法方向或确实需要同时修改冲突代码的并行工作才新建分支，
并在这一方法族内复用。工作结束后，把需要继续维护的修改并入相应主线，
其余历史状态保存在标签中，再收掉临时分支。长实验需要冻结代码时，
可使用指向明确提交的 detached worktree，不为每次运行再建立分支。
