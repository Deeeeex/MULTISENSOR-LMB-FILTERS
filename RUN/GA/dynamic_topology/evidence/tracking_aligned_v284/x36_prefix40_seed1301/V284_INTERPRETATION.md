# X36：目标集合恢复有明显信号，但定位代价尚未解决

这一轮完成了同场景、同种子、同发送与到达边的 40 步配对实验。
它不是 160 步全程结果，也不是独立种子验证。唯一的候选干预是：
存在有观测历史的输入时，排除从未接触观测信息的先验输入。
漏检仍是信息；历史信息不会因为当前离开视域而被丢弃。

## 主要结果

| 指标，越小越好 | 原稀疏骨干 V242 | 加入先验排除 V284 | 变化 |
| --- | ---: | ---: | ---: |
| E-OSPA / m | 135.180 | 117.117 | 改善 13.362% |
| 数量绝对误差 | 19.501 | 14.474 | 改善 25.782% |
| 官方匹配 RMSE / m | 8.425 | 22.303 | 恶化 164.715% |
| 六个代表节点的平均分歧 / m | 144.670 | 115.117 | 改善 20.428% |
| 尝试发送的后验字节 | 18,435,344 | 18,442,200 | 增加 0.037% |

36 个节点的平均 E-OSPA 均改善，六个编队的改善范围为 9.889%--16.579%；
但各节点的官方 RMSE 也均恶化。两种方案都在全部 1,440 个节点--时刻上
有有限 RMSE，因此这次不是空输出被排除出均值造成的差异。
发送数均为 1,840，到达数均为 1,766，边--时刻条目逐项相同。
352,792 字节的新增标记开销已计入上述总量。

真实目标数始终是 24。平均输出目标数由 4.499 增加到 9.526；两组均未
出现输出数量超过真值的时刻。数量改善贯穿前缀，不只出现在启动两步：

| 时间段 | 原方案数量误差 | 候选数量误差 | 排除的输入--标签次数 |
| --- | ---: | ---: | ---: |
| 1--5 | 20.433 | 18.433 | 495 |
| 6--20 | 20.007 | 13.724 | 962 |
| 21--40 | 18.889 | 14.046 | 213 |

数量增多本身不证明目标身份正确。它与 E-OSPA 的共同改善构成有价值的
集合估计信号，但尚不能替代目标身份、全程稳定性和跨种子验证。

## RMSE 为什么会大幅上升

对每个节点--时刻，两组估计分别与同一组真实位置做最小总距离匹配，再
区分共同匹配的真实位置、新增匹配位置和不再匹配的位置。这是事后解释，
不是修改评估对象或重新判定通过。

| 匹配组成 | 匹配对数量 | 原方案汇总 RMSE / m | 候选汇总 RMSE / m |
| --- | ---: | ---: | ---: |
| 共同匹配位置 | 5,868 | 8.730 | 8.898 |
| 仅候选匹配位置 | 7,850 | 不适用 | 34.731 |
| 仅原方案匹配位置 | 610 | 见逐项数据 | 不适用 |

这里的汇总 RMSE 是先合并距离平方再开方，与官方“每个节点--时刻的
RMSE 再取平均”不同，不能拿它代替主指标。匹配对重复包含不同节点与
时刻，不是独立样本；“共同位置”也不是已经确认的同一轨迹标签身份。

新增匹配部分在第 5、6 编队的汇总 RMSE 分别为 50.216、58.463 m，
高于第 1--3 编队的 13.350--19.494 m。共同匹配部分只是小幅变化，
说明大幅 RMSE 增长主要伴随新增目标的定位质量不足；同时仍有 610 个
原方案匹配对不再出现，不能描述成完全无损地保留旧目标。

## 对主线的影响

1. V283 中“后段很少再有未更新先验”不等于“早段先验处理没有持续影响”。
   本轮实际干预改变了后续轨迹，提供了明确的启动处理影响证据。
2. 仍然没有达到联合目标。冻结筛选因 RMSE 失败；同前缀静态路由的
   官方 RMSE 是 8.754 m，候选相对它也退化。不能通过换比较对象或只选
   共同匹配部分，把失败改写成成功。
3. 不继续扫描启动规则阈值，也不因此启动全程性能验证。下一项方法决策
   是：新增目标的位置不准，究竟因为网络里本来没有足够准确的同标签
   信息，还是这份信息没有及时送到需要它的节点？前者需要改估计/观测，
   后者才支持进一步设计按信息时效与需求分配的路由。
4. “相对基线新增匹配的目标”是离线诊断定义，不能作为在线控制器的输入。
   后续控制必须使用本地后验、真实可获得的标签与时效信息，并计通信成本。

原始发送/到达图、感知范围、路由权重、空间近似和输出规则未被另行调整。
这不是标准多视域 LMB 算法的完整复现，也不单独构成新理论贡献。
本轮结果和图保留在实验记录；论文主表及 Lark 最优策略表不作成功升级。
