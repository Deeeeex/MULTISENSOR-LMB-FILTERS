# V116: privileged delayed label-return oracle

## Purpose

V115 shows that current association support, existence and receiver need all
recreate the full V113 boundary behavior.  V116 asks a narrower question:
does any interpretable label subset between V114's empty boundary and V113's
full boundary have enough delayed H=8 return to pass the X36 gate?

## Frozen candidate family

The V115 supported-arm trajectory is replayed once with posterior capture.
On pages 5--8, the 22 active sender-27 labels are matched one-to-one to the 24
current target states using privileged truth and ranked by Euclidean position
error.  Three very low-existence labels are 400--570 m from their nearest
targets; the remaining labels span roughly 1--54 m.  Before any V116 outcome
is opened, the following quotas are frozen:

| Arm | Boundary labels per page | Meaning |
|:--|--:|:--|
| top-5 | 5 | highest-precision core |
| top-10 | 10 | precision-focused half |
| top-15 | 15 | broader truth-aligned set |

Each admitted label carries its complete Bernoulli Gaussian mixture.  Every
omitted label explicitly abstains from its KLA update.  F2--F5 keep V113
whole-source abstention, and only edge `27 -> 32` uses the quota.

## Decision rule

The physical carrier, weights, link opportunities, delivery uniforms,
filter RNG, control synopsis accounting and rolling B3 route remain paired.
V113 full boundary entry and V114 empty boundary entry are the endpoints.
The three frozen quotas are evaluated by complete H=8 tracking return.

A quota passes only with at least five-percent mean and mature-page gain
against clockwise full, nonnegative minimum formation, F6 non-gateway tail,
worst sensor, consensus and byte changes, and rolling B3.  A pass proves that
label-wise boundary control has action-space headroom and defines the delayed
value target for a temporal model.  Failure of all three truth-ranked quotas
does not mathematically exclude every subset, but it closes simple
truth-alignment ranking as a viable upper bound and redirects the next test
to an alternative physical source or carrier.

V116 uses current truth to construct the candidate sets and future outcomes
to select the reported oracle.  It is privileged development evidence only.
