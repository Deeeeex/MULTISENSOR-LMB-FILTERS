# V124: keep F6 on the reference row

V123 fails because the F1-to-F6 row is locally beneficial for two pages but
creates a large delayed F6 reversal.  V124 removes only this row switch.  F6
uses the clockwise reference input on all eight pages; every F1/F3 row choice
and every payload-participation page remains identical to V123.

The simplified sequence preserves 60 messages, physicality, row weights and
rolling B3 without any connectivity fallback.  It must reach at least 5% mean
gain versus clockwise full, at least 5% on every page from page four, and keep
all formation, terminal, worst-node, consensus and byte metrics nonnegative.

Failure closes additive row composition and requires joint finite-horizon
sequence-value modeling.  V124 is opened development evidence only.
