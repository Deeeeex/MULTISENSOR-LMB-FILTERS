# V134: set-valued protection pulses with conservative policy iteration

## Why V133 is not the closed-loop method

V133 correctly defines the causal effect of withholding one receiver formation's incoming cross-formation posterior for one page and measures its downstream tracking regret over one propagation horizon.  It is useful as an atomic effect model.  Its first dataset design, however, samples only isolated single-formation actions from states generated by the static full-posterior carrier.  A full-episode controller would visit different posterior states after its own actions and would usually need to protect several receiver formations together to obtain material network benefit.  Training a per-formation classifier on the static state distribution and then repeatedly applying it would therefore mismatch the deployed state and action distributions.

V134 keeps the valid parts of V133---the frozen static carrier, actual payload-abstention semantics, mixture-aware current state, paired random streams and propagation-horizon outcome---but changes the decision object and the data collection loop.

## Action: one set pulse followed by recovery

At an eligible page, the controller chooses a receiver-formation set \(A_k\).  For every formation in \(A_k\), incoming cross-formation posterior payloads are withheld on the current page.  The physical and logical route, fusion weights and attempted carrier edges remain unchanged; a charged control synopsis indicates abstention, and an absent payload is not interpreted as negative label evidence.

The pulse lasts one page.  The next \(D_F\) pages use the frozen full-posterior carrier, where \(D_F\) is the directed formation-cycle diameter.  No new pulse is allowed during this recovery interval.  This makes the deployed action identical to the counterfactual evaluated by its multi-step teacher and prevents unmodelled overlapping action effects.  It is also consistent across scale: the recovery interval is determined by propagation distance rather than a hand-tuned absolute duration.

The action budget is expressed as the fraction of reference cross-formation payload bytes withheld on the pulse page.  Candidate sets must provide positive byte saving after charging control metadata.  The reference action \(A_k=\varnothing\) is always available.

## Candidate-set construction

Enumerating all nonempty subsets is feasible for the initial four- and six-formation scenes, but the deployed rule must remain extensible.  Candidate formation scores are computed from current observable information only:

- the exact one-page mixture-aware abstention change in task risk, disagreement and label retention;
- sender--receiver posterior mismatch, observation quality and recent delivery opportunity;
- scale-normalized downstream reach over the formation graph.

These scores produce a deterministic nested family: the empty reference plus prefixes of formations ordered by predicted benefit per charged byte.  Dominated prefixes are removed.  For M24/X36 the full subset bank is retained offline as an oracle audit, while the nested bank is the deployable action space.  The method advances only if the best deployable set reaches at least 5% paired mean and mature E-OSPA gain on both scales without a registered local regression; otherwise the action space, not the learner, is rejected.

## Multi-objective teacher target

Every candidate set is evaluated from the same pre-action state against an empty-set reference.  Both continuations share measurements, delivery uniforms, filter RNG, route and fusion weights.  The horizon is one pulse page plus the directed formation-cycle diameter.

The teacher retains a vector outcome rather than collapsing all local and network effects into one class:

1. mean and mature network E-OSPA gain;
2. worst-sensor and worst-formation gain;
3. worst causally reachable downstream-formation gain;
4. terminal posterior-disagreement change;
5. attempted and delivered byte saving.

An action is admissible only when the conservative upper confidence bounds of every registered regret component are nonpositive.  Among admissible actions, the controller maximizes a lower confidence bound on mean E-OSPA gain plus a fixed communication-saving utility.  The empty-set static action is used whenever no nonempty action is certified.

This separates safety from utility.  It avoids treating a harmless but useless action as a success, and it avoids asking one logistic probability to represent heterogeneous regret magnitudes.

## On-policy dataset aggregation

Iteration zero uses static-carrier states to establish atomic and set-action headroom.  After fitting the first conservative surrogate, complete development trajectories are rolled out with the actual one-pulse-plus-recovery controller.  Fresh paired counterfactual labels are generated only at states visited by that controller, then aggregated with the earlier data.  Iteration continues until both scales satisfy all of the following:

- the action distribution changes by less than 5 percentage points between two iterations;
- harmful-action recall is at least 90% and false-safe rate at most 5% on complete held-out calibration trajectories;
- nonempty pulse coverage is at least 10%;
- at least half of deployable-oracle gain is retained separately on M24 and X36.

Scene--seed trajectories remain indivisible across development, calibration and validation.  Truth and future outcomes appear only in offline labels; they never enter features or runtime action selection.  If a visited state lies outside development support, the policy falls back to the empty-set static action.

## Model hierarchy

The first model is a shared, scale-normalized additive set model with calibrated residual bounds.  It combines per-formation risk/utility predictions with explicit set-size, byte-budget and overlap terms.  This form is permutation invariant and interpretable.  A GNN or learned set encoder is authorized only if the frozen additive model leaves a repeatable interaction residual on both scales and the richer model improves held-out safe utility without weakening any safety gate.

## Evaluation order

1. Freeze the stronger full-trajectory CW/CCW static carrier independently for M24 and X36.
2. Measure full-subset and nested-deployable oracle headroom on registered development trajectories.
3. Stop if the nested action space cannot meet the 5% cross-scale gate.
4. Run on-policy dataset aggregation and freeze the smallest gate-passing model.
5. Evaluate once on unseen radial seeds.
6. Only after the radial model is frozen, evaluate convoy and relay as held-out geometry; use crossing only as an extreme stress test.

Failures and intermediate iterations remain repository records.  The main progress document receives V134 only after the unseen-seed tracking gate passes on both M24 and X36, or after a repeated mechanism result changes the method decision.
