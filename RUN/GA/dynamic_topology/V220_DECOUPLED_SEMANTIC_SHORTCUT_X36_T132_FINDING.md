# V220 decoupled semantic shortcut: X36 t=132 finding

## Decision

Retain the causal communication-donor head, but reject **post-fusion
common-support residual label KLA** as the primary beneficiary action.

The X36 seed-1301, t=132 screen establishes three facts:

1. a safe communication donor exists and can improve tracking while saving
   attempted bytes;
2. the bounded observable candidate bank can find executable cross-formation
   complete-label actions without truth or future information; but
3. applying the selected label as an additional KLA update after ordinary
   fusion is either harmful or too small to justify its payload. A more
   expensive high-risk-reduction candidate improves E-OSPA and consensus but
   worsens position RMSE, so the limitation is not just the fixed 20% credit
   reserve.

No larger V220 trajectory collection or GNN fitting is authorized. The next
action semantics should route the selected complete label into the ordinary
KLA input set exactly once, replacing a low-value/conflicting input and
renormalizing label-wise weights, rather than adding a second residual fusion
after ordinary fusion.

## Mechanistic interpretation

V220 currently performs ordinary full-posterior fusion first and then applies
another two-input componentwise powered-GM KLA to the beneficiary label. This
has two weaknesses:

- the external source can already influence the ordinary fused state through
  the protected backbone, so the residual update can reuse correlated
  information without an explicit independence argument; and
- a single fixed source weight can improve existence/cardinality agreement
  while pulling the spatial density away from the position-accurate mode.

The observed E-OSPA/consensus versus RMSE split is consistent with this action
semantics. It does not prove that every residual KLA action is harmful, but it
is sufficient to reject the current action family as the main scalable method.

## Successor action: label-wise effective-KLA input routing

Keep the V218/V219 scale-aware graph state, trajectory-grouped splits, and
finite-horizon labels. Keep V220 stage-1 donor safety and exact byte ledger.
Replace only stage 2:

1. identify one beneficiary label and the ordinary fusion inputs currently
   available for that label;
2. choose one physically delivered complete-label source;
3. replace or suppress one low-value/conflicting label input rather than
   appending a second fusion;
4. renormalize the label-wise KLA weights and perform mixture-aware KLA once;
5. preserve every other label and the registered full-posterior backbone; and
6. fall back to the static input set when the overlap, support, byte, or
   calibrated-value projection fails.

This makes the learned object the **effective KLA graph for one label**, not a
generic denser communication graph and not a post-hoc state correction. The
theory can analyze how one input substitution changes the Bernoulli logit and
the spatial-overlap factor eta_l; the experiment can compare the same no-op,
donor-only, same-formation, generic full-mixing, and teacher upper-bound
controls already defined.

Before collecting more trajectories, a small H=3 mechanism bank at the same
X36 t=118/t=132 caches must show a material E-OSPA/RMSE/consensus improvement
with positive real attempted-byte saving. Current-best Lark tables remain
V187 (strategy) and V206 (mechanism).

## Evidence boundary

These are paired development results from one X36 scene, seed, and time. The
synthetic-credit arm is a mechanism upper bound only. The evidence rejects an
action semantics; it does not establish a held-out or cross-scene method
claim.
