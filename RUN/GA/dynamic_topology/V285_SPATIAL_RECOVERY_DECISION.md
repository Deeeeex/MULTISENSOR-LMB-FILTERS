# V285：新增目标的位置精度能否靠信息传递改善

Status: decision-stage design only; no new candidate or filter run.

## 已有依据

V284 的 40 步 X36 干预使 E-OSPA 改善 13.362%，代表节点分歧改善
20.428%，后验字节几乎不变，但官方 RMSE 明显退化，联合筛选失败。
事后匹配组成显示，误差主要集中在新增加的匹配位置，尤其第 5、6 编队。
这一事实足以改变下一步问题，但不支持重新调启动阈值或声称方法已经成功。

## 一个必须先回答的方法问题

对于这些位置误差较大的输出，网络中是否已有更准确的**同标签**估计？

- 若几乎不存在，更快的传递也无法凭空生成定位信息；应先处理局部估计、
  多视域融合或观测条件，不能继续堆叠路由/学习器。
- 若存在，但集中在别处，才进一步检验当前真实链路和时序能否传递它，
  以及本地后验不确定性、观测更新时间等可用特征能否识别它。

## 最小离线检查

复用 V284 已保存的 `estimates`：已经确认其中有逐时刻 `labels`、`mu`、
`Sigma`，不需要再跑滤波。使用同一标签的匹配位置，区分全网络、同编队
和当前入邻居中的可用估计。保留全部新增匹配情况及各编队统计，不只挑
误差最大的例子。

真值只用于离线解释与理想上限，不能进入在线评分。按真值选择最佳源是
乐观上限，不是可部署方法；按后验位置不确定性选择源也仅是未计控制通信
的可识别性检查，不是已实现的新路由。不同标签之间不能靠真值直接对齐后
假装可以交换融合。当前保存的是轮末估计，不能假装它已在同轮决策前可用。

如果存在可用信息差，再定义**下一时刻可执行**的完整标签后验传递动作，
显式预测消息时效、经过真实物理链路、计入元数据及失败尝试成本，并比较
接收端的集合与空间后果。任何新全程比较都必须包含同融合规则的静态组。

## 理论与设计边界

后续的主问题应是“在有限通信预算下，让尚不准确的目标估计及时获得有效
位置更新”，而不仅是让图更连通或平均混合更快。理论必须把消息时效/信息
质量与明确的估计误差量联系起来，并清楚列出标签一致性、模型和近似假设；
目前尚没有这样的新结果。

V284 的观测历史标记只回答是否接触过信息，不等于当前定位信息新鲜。
漏检对目标存在性有意义，但不能不加区分地当作获得了新的位置测量。
V268--V270 的单次原始后验转发已显示递归集合损失，不能直接把那个动作
重新命名后复用，也不能只凭一轮存在概率安全就断言后续安全。

本轮只作上述有明确分支的问题分析。尚无依据添加 GNN、启动参数网格、
改动场景范围/FoV，或升级论文与最优策略表。
