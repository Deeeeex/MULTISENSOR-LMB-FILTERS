# V152 safe graph-codebook outcome

## Decision

The frozen V152 M24 seed-83 pilot fails its strict budget-neutral gate, so it
does not authorize X36 or GNN training under the V152 contract.  None of the
six dynamic graphs is admissible because every one increases realized
full-posterior bytes relative to the better static CW trajectory.

This is not a null action-space result.  Rank 4 is a clear fixed-opportunity
Pareto point: with the same 40 directed messages per page and all physical and
rolling-connectivity checks satisfied, it improves mean E-OSPA by 13.013%,
worst-sensor E-OSPA by 37.149%, minimum-formation E-OSPA by 4.262%, and
consensus OSPA by 13.286%.  Its realized attempted bytes increase by 1.962%.

The valid conclusion is therefore narrower: complete projector-safe graph
choice has material estimation headroom at a fixed transmission-opportunity
budget, but V152 has not established byte-neutral improvement.  In particular,
equal message count does not imply equal bytes because the chosen information
flow changes both the selected senders and the later posterior complexity.

## Next method boundary

V153 must state the resource model before opening more outcomes.  The primary
action constraint should remain the exact directed-message budget, while
realized bytes must be modeled explicitly as a second cost rather than hidden
inside admissibility.  A deployable selector should rank only complete safe
graphs, predict both tracking value and payload cost from current observable
posterior metadata, and retain the static CW action as a conservative fallback.

The next headroom screen should report a tracking--byte Pareto frontier on X36
and on the remaining pre-registered development seeds.  No stable cross-scale
claim is permitted until both scales show material gains without tail or
consensus regression and the byte trade-off is declared prospectively.
