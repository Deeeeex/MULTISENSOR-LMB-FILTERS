# V265 label-selective risk shortcut

## Method decision

V261--V264 establish two complementary facts on the opened M24 event.  A
shorter F1--F3--F4 information path has real localization leverage, but every
full-posterior topology change also changes the KLA inputs of unrelated
labels and formations.  A tree loses useful incumbent relations; adding one
protective cycle recovers only part of that damage and spends extra full
posterior bytes.

V265 therefore keeps the V242 full-posterior backbone, message count and
fusion weights unchanged.  Dynamic control moves from the physical topology
to the effective per-label KLA graph.  When the causal V261 risk rule detects
a high localization tail and a lower-risk donor copy of the same label, V265
sends only that complete labeled Bernoulli Gaussian-mixture density across
the first missing physical hop of the shorter formation path.

## Executed action

For one selected label and one selected receiver:

1. choose the donor sensor with an active, low-covariance copy of the label;
2. prefer a physically reachable relay sensor that is already the V242
   outbound gateway toward the at-risk formation;
3. charge the complete label payload on that physical link even if delivery
   or the receiver-side safety projection fails;
4. append the delivered label with zero global topology mass;
5. assign it the frozen V242 cross-residual share `0.05` only for this label;
6. execute one ordinary label-wise KLA call; and
7. recover the ordinary V242 fusion result if the candidate fused existence
   log odds move by more than `0.25` or cross the `0.5` MAP threshold.

The appended input has zero weight for every other label.  Thus the action
does not alter unrelated-label KLA weights, unlike V261--V264 full-posterior
route changes.  The eta guard is exact for the normalizer returned by the
installed fusion path; that path still uses the repository's powered-GM
approximation and is not presented as an exact arbitrary-mixture KLA proof.

## First paired result

The `t=57--73` continuation improved network RMSE by `4.660%`, F4 event RMSE
by `12.353%`, and consistency by `0.044%` over the stored V242 continuation.
Network E-OSPA regressed by `0.026%`, F4 event E-OSPA regressed by `0.065%`,
and the weakest-formation RMSE did not improve.  Thirteen label messages were
scheduled, nine were delivered, but only the messages at `t=57` and `t=59`
passed the receiver-side existence-retention projection.  The result therefore
establishes localization leverage but fails the registered joint gate.

The next replay records the donor/target risk values and the exact projection
margin on each page.  This is the minimum diagnostic needed to distinguish
transport loss, a non-complementary donor, and rejection by the existence
guard before changing the action itself.

## Evidence boundary and next decision

The scenario, seed and event were opened by V259, so a positive result is
development evidence only.  A pass authorizes one complete M24 run with the
same rule.  A failure does not authorize a weight sweep or GNN; first separate
source-selection error, one-hop propagation latency and insufficient
label-specific influence.  A learned value ranker is considered only after
the deterministic action family shows material headroom.
