# V145 pre-outcome freeze: protection-load-gated W/R routing

Frozen before opening any V145 tracking result.  V144 showed that one extra W
page improves the immediate M24 response but leaves a persistent, uneven
reference-lineage error.  The fixed periodic branch is closed; V145 tests one
state-dependent analytic gate before any learned edge scorer is trained.

## Observable rule

The physical route, nominal KLA weights, attempted opportunities and one-full-
posterior-per-edge contract remain unchanged.

1. The first continuation page sends R on every edge to establish a common
   reference anchor.
2. On later pages, a protected intra-formation edge sends W only while more
   than half of the formations are still protected from their cross input.
   Cross-formation edges and unprotected receivers always send R.
3. When the protected-formation fraction becomes at most one half, the role
   gate latches to all-R for the rest of the continuation.
4. The gate reads only the current formation-protection mask.  It reads no
   truth, future outcome, numeric sensor identity or paired-run result.

For the frozen V134 action, the resulting page-level role envelope is
`R-W-W-W-R-R-...`; individual receivers that rejoin earlier already revert to
R.  The longest R-withholding prefix is therefore no worse than the audited
V144 prefix, whose M24/X36 terminal maximum-row TV values are below `0.025`.
After the latch, all-reference mixing can only restore reference flow.

## Gate and decision

V145 inherits the joint M24/X36 tracking, worst-sensor, worst-formation,
rejoin, zero-auxiliary and no-byte-increase gates.  M24 runs once.  Failure is
repository-only, does not open X36, and moves directly to an edge-level
counterfactual teacher plus deterministic time-expanded projection.  A joint
pass promotes this observable rule to the analytic baseline; a GNN is then
justified only if an edge-level teacher retains additional stable headroom.
