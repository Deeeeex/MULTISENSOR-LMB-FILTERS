# V147 spatial label-support debt routing

## Method question

V142 showed that a small number of spatially supported missing label states
contains useful tracking information on both registered scales, but it used a
second complete posterior lineage and increased attempted communication by
about 89%. V143--V146 then showed that alternating or repartitioning whole
posteriors cannot recover that effect reliably. V147 asks the narrower
first-principles question: can the useful source already be reached by
reassigning one existing directed message, while sending exactly one complete
mixture-aware LMB posterior on every selected edge?

The action is deliberately below formation level. For one receiver row it
may replace the current cross-formation residual sender by a physically
reachable source whose current posterior contains label support missing or
spatially misaligned at the receiver. A stronger variant promotes that source
to the existing 0.70 role and demotes the incumbent dominant source to 0.05.
The self weight, number of messages and row-wise weight multiset remain
unchanged.

## Current-only value and protection rule

For every feasible receiver--source pair, V147 performs the installed
mixture-aware, FoV-censored LMB-KLA once for the reference row and once for the
candidate row. It scores only current observable posteriors, current sensor
geometry and current link reliability. A candidate receives credit when the
fused existence probability or spatial state moves toward a source-supported
label. It is charged for moving away from any label supported by the receiver
or either incumbent source. A row is retained only if predicted gain exceeds
predicted harm, no protected label crosses downward through the `r=0.5`
decision boundary, and protected harm is no larger than predicted gain.

This is a causal surrogate, not a tracking oracle. It reads no target truth,
future measurement or future outcome. Moment matching is used only to score
spatial alignment; the counterfactual fusion itself retains the installed
powered-GM mixture-aware receiver.

## Graph projection and frozen action bank

Safe rows are composed with at most one changed receiver per formation. The
projector requires:

- every directed edge to be physically reachable;
- the same row message counts and the same row-wise KLA-weight multiset as
  the reference;
- an instantly strongly connected sensor graph;
- no increase in exact current full-posterior payload bytes; and
- one reference graph immediately after the finite intervention.

The frozen bank contains single-formation, half-formation and maximum feasible
coverage for dominant promotion, plus maximum feasible residual replacement.
The temporal candidates use either pages `1:3` or pages `[1,2,3,5]`. M24 is
screened first. Only an identical M24-passing action index may open X36.

## Outcome gate

An opened action must improve intervention-window mean E-OSPA by at least 5%,
have nonnegative full and mature-window gains, and keep every sensor,
formation and consensus window above the registered `-0.01%` tolerance. It
must execute on every requested page, return exactly to the reference graph,
preserve message and weight structure, pass rolling three-page sensor and
formation connectivity, and introduce no attempted-byte increase.

All outcomes are development evidence. A single-scale result, a failed arm or
a bank with no feasible action remains repository-only. GNN training is not
authorized unless one frozen action exposes joint M24/X36 headroom.

## Interpretation boundary

The term *support debt* in V147 describes a current-state discrepancy. It is
not yet a measured multi-step support age. If the fixed current-state bank is
too narrow, the correct successor is not threshold tuning: it must either
carry a causal label-support history online or change the communication
decision object from a whole posterior row to a budgeted edge--label payload.
