# V118: fixed-entry alternative F5 source

## Purpose

V116 closes label subsets on `27 -> 32`; V117 closes moving receiver 32 to
another F6 entry.  V118 isolates the final single-source local variable: can
another F5 posterior enter the same receiver 32 with a positive H=8 return?

## Frozen action family

The clockwise carrier, F2--F5 abstention schedule, receiver 32, F6 internal
graph, `33 -> 2` return edge, cross weight `0.05` and message count remain
fixed.  The original source 27 is replaced by each other F5 member: 25, 26,
28, 29 and 30.  No current score chooses a subset; all five alternatives are
exhausted.

A literal one-edge replacement is invalid: `27 -> 32` is node 27's only
outward influence, so deleting it disconnects node 27 for every candidate.
V118 therefore uses the minimum common connectivity repair: the fixed
`25 -> 26` intra-F5 role becomes `27 -> 26`, with receiver 26's original
weight unchanged.  Thus each candidate migrates two source roles but adds no
edge, and the repair is identical across all five source comparisons.

Each paired rewire must preserve row sums, the nonzero weight multiset, exact
message count, static strong connectivity, physicality and rolling B3 before
its tracking result is admitted.

## Decision rule

The gate is unchanged: at least five-percent mean and mature-page gain versus
clockwise full, nonnegative minimum formation, F6-peer, worst-sensor,
consensus and communication changes, and rolling B3.  V113 source 27, V114
empty boundary, V116 top-5 and the best V117 gateway remain endpoints.

A pass establishes paired source-role headroom and authorizes a causal source-
value model.  Failure closes this minimum-connectivity source migration at the
F5-to-F6 boundary and forces the next method to change the formation-level
carrier or use a budget-matched multi-source entry.  The anchor and action
family follow opened V113--V117 evidence, and future H=8 outcomes select the
reported oracle, so V118 is privileged development evidence only.
