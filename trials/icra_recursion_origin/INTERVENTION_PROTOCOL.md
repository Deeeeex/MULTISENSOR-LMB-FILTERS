# One-time intervention at the first distribution divergence

The complete origin trace and independent native-count check are available
before this registration. In all four model/link cells the first meaningful
GCE/Guarded Scalar fused-distribution difference is frame 3. Both local
source distributions are equal within the frozen numerical tolerances;
small earlier roundoff differences are retained and not called exact parity.
Matching is the same. The first meaningful local update difference follows
at frame 4. These timings do not establish that frame 3 causes the eventual
target failure.

Test only the already designated range-model, intermittent-link,
`v2xt_0001` fragmentation case. Its original Guarded Scalar target result
in frames 53--122 is 9/140 robot frames, versus 118/140 for both GCE and
No-age. This is an exposed diagnostic case, not a method-selection dataset.
The failed shared range-model screen stays closed.

Run Guarded Scalar from the beginning. At every received fusion in frame 3,
compute both the ordinary Guarded Scalar and GCE distributions on that
same execution's inputs. Apply exactly one of three predeclared substitutions
to all output labels at that frame:

1. `once_joint`: use the GCE existence and spatial distribution.
2. `once_existence`: use only the GCE existence; keep the scalar spatial
   density and covariance.
3. `once_spatial`: use only the GCE mean and covariance; keep scalar existence.

At every other frame use the unchanged Guarded Scalar recursion. Never use
truth, a target identity, a spatial neighborhood, a score outcome or a
delivery outcome to select which labels receive the intervention. Frame 3
comes from the frozen earliest-distribution trace. No repeated correction,
longer intervention interval, alternative start frame or gain factor is
selected after outcomes. Log the old, GCE and applied distributions for
every intervened label, while preserving the real packet and full-recursion
records.

First rerun the unchanged GCE and Guarded Scalar range arms under the same
new runner and require exact original common-field parity. Freeze this
preflight and all three intervention runs before their outcomes. Require
successful native exits and complete source, observation, probability,
Gaussian, packet and extraction checks. Validate the component substitution
on analytic fusion fixtures before these runs. Intervention trajectories
must equal their Guarded Scalar control before frame 3, and use precisely
the original equations outside the registered event.

Report all five new trajectories and the audited original No-age reference.
Report full-sequence OSPA/GOSPA, all target robot frames (including the
previous 53--122 window), missed/false/localization costs, candidate counts,
association concentration, and native payload/wire bytes. No intervention
can be promoted as a new algorithm from this case. A successful replacement
would support that this initial state change can alter the later outcome;
it would not establish that the first event is the only cause. Failure of
the three substitutions would show that this one-time intervention is
insufficient, and ends this exact experiment without extending its duration.
