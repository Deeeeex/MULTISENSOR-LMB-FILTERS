# Curvature filtering of opposing current evidence

The nominal-origin experiment showed a first event where a proposed positive
increment was rejected by the spatial curvature check while an opposing
negative increment survived. Cancelling that event once did not repair the
recursive failure. This protocol does not move or extend that intervention.
It tests a time-invariant receiver rule on the complete predeclared cohorts.

Earlier families restored rejected scalars, projected their spatial ratios,
scaled all sign-conflicting increments by spatial overlap, or removed all
additional negative evidence. None tested the rule below. Their failures and
all original data remain intact. This is a bounded heuristic hypothesis;
neither source disagreement nor curvature rejection identifies ground truth.

For each aligned label, compute exactly the original GCE history weights,
proposed current exponents, source curvature decisions, and aggregate
fallback. A sign is represented by a strictly nonzero current log-odds
increment with a positive proposed exponent. Define two events:

- P: a positive proposed increment is rejected by the source curvature
  check, and an opposing negative increment has a positive final exponent.
- N: a negative proposed increment is rejected by the source curvature
  check, and an opposing positive increment has a positive final exponent.

The sole primary, `paired_veto`, sets all extra current exponents for that
label to zero when P or N occurs. Recompute existence from the unchanged
history pool and the original spatial pool integral; use the original
spatial pool. The ordinary local posteriors, including their negative
information, remain in that pool. Otherwise retain the original output
exactly. There is no threshold, fitted coefficient, time window, target
identity, extra packet field, or truth-dependent choice. Sources that had
zero proposed support do not trigger this rule. An original aggregate
fallback with no surviving exponent does not trigger it either.

Keep `original`, `positive_rejected_veto` (P only), and
`negative_rejected_veto` (N only) as fixed controls. The directional controls
are mechanism decompositions, never alternative primaries. In Guarded
Scalar, use the identical decisions on its own visited inputs and retain
its original spatial pool throughout.

First score all original nine V2V4Real development segments and all five
previously inspected V2X-Real validation segments, both radio conditions,
on the separately visited GCE and Guarded Scalar states: 56 saved source
runs, four output rules. Reuse the exact roster and source hashes from the
completed joint-admission diagnostic. The already inspected nominal-origin
test case is excluded from selection. All these inputs are development
data, including the earlier reviewer's recording; no fresh generalization
claim is available from this screen.

Before computing any alternate score, freeze this protocol, fixtures,
producer, independent verifier, launch script, and all input dependencies.
Check every original fused distribution and exact original extracted set.
Verify changed distributions separately from transmitted Gaussian ratios,
plus a separate cardinality recurrence, assignment scores, and all decisions.
Report both directional event counts, existence changes, and localization,
miss, false, cardinality and OSPA costs for every rule and source backend.
No same-input substitution is described as a new recursive trajectory.

Advance only if primary GCE-state mean OSPA is strictly lower than original
in each of the four dataset-by-radio cells. If any cell fails, close this
rule without changing its signs, support conditions, or cohort. If all pass,
freeze and run full recursions of the primary and its matching Guarded Scalar
control on all 14 segments and both radios (56 new trajectories), reusing
audited original GCE, Guarded Scalar and No-age references. Require at least
1% primary improvement over original GCE in each dataset's two-radio mean,
strict improvement in each dataset-by-radio cell, and lower two-radio means
than matched Guarded Scalar and No-age in each dataset. Only then extend to
the remaining already exposed recordings and seek unused recordings for
independent validation. A favorable directional control is not promoted.
