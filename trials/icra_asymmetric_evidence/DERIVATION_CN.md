# 固定当前输入下的性质与优化解释

以下性质针对已经确定的输入、资格、关联分布和当前观测支持，不是完整递推
中的误报、漏检或 OSPA 保证。符号与本目录 PROTOCOL.md 一致。

设归一化关联权重包含漏检分支 W0，检测分支之和为 a=1−W0。正向分数
对比量 v_m=max(0,(L_m−1)/(L_m+1)) 属于 [0,1]；负向漏检对比量
u=pD/(2−pD) 也属于 [0,1]。因此

    0 ≤ g+ = sum_m W_m v_m ≤ a,
    0 ≤ g− = (1−a) u ≤ 1−a,
    g+ + g− ≤ 1.

这表示两个门控使用不同观测分支的有界支持预算，不能把任意一个门控解释为
真实存在概率或频率学置信度。无当前观测机会时二者为零；空量测但当前可见时，
a=0，保留名义漏检模型能够提供的负支持。真实遮挡若未反映在 pD 中，负支持
仍可能过强。检测分数无法判别目标与杂波时 L=1，正支持为零；这不是缺少分数
模块时自动启用单位分数的规则。后者只有明确的 no-mark 消融才使用。

令每个来源的有效增量为

    e_j = g+_j max(delta_j,0) + g−_j min(delta_j,0).

它满足 min(delta_j,0) ≤ e_j ≤ max(delta_j,0)。在固定合格来源、权重 beta
及空间密度时，额外对数几率修正是 E=sum_j(1−beta_j)e_j。因此

    base + sum_j(1−beta_j)min(delta_j,0)
       ≤ z_AE ≤
    base + sum_j(1−beta_j)max(delta_j,0).

这里 base=sum beta_j logit(r_j)+log(eta)。同一标签没有至少两个合格且已表示
来源时，按定义 E=0。与只准许正向增量不同，z_AE 可以高于或低于保守继承项。
单源时剩余系数为零；零增量时无附加项；所有负门控为零时精确恢复上一轮的
正向选择性规则。门控取到 1 的代数端点仅用于检查，不表示名义 pD=0.9 的
漏检门控实际能达到 1。

历史权重规则选取 beta=q 当 age=sum(q−b)logit(r)<−1e−12，否则 beta=b。
其 base 与严格 min(z_NoAge,z_ER) 的差最多为 1e−12 对数几率；由于 logistic
导数不超过 1/4，概率差最多为 2.5e−13。该容差避免数值相等时权重选择不定，
而不是在结果上拟合的融合阈值。

若空间权重为 alpha，输入空间密度为 p_j，定义当前输入下的目标

    J(r,p) = sum_j beta_j D_B(r || r_j)
             + r sum_j alpha_j KL(p || p_j) − r E.

beta、alpha、E 在这次优化中固定。空间最优解仍为原有的归一化几何池化
p_alpha，归一化常数为 eta。代入后，标量目标导数为

    dJ/dr = logit(r) − sum_j beta_j logit(r_j) − log(eta) − E,
    d²J/dr² = 1/[r(1−r)] > 0.

因此唯一内部最优解就是实现中的 logistic(base+E)。额外线性项是一项设计的
有效证据修正；这一优化解释没有证明 e_j 是独立真实似然，也没有修复局部 LMB
关联近似、不同先验或检测器相关性。不能据此宣称精确集中式 Bayes 融合。

每次融合保持同一输入的空间解，仍不能保证整个轨迹的空间估计不变：存在值
会改变后续关联、剪枝、基数提取和下一帧输入。实验必须使用完整递推及组件
对照，不能把本文件的界限替代为经验性能结论。
